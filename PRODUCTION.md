# AEON OS — Production Operations Guide

AEON OS runs as a **single full-stack deployment on Oracle Cloud**: Next.js
frontend, Flask kernel, Postgres database, and Caddy TLS proxy all live on one
Compute VM via Docker Compose. See [DEPLOY.md](DEPLOY.md) and
[DEPLOY_ORACLE.md](DEPLOY_ORACLE.md) for setup; this guide covers operating
the stack in production.

## Architecture Overview

| Component | Stack | Runs as | Notes |
|-----------|-------|---------|-------|
| Frontend | Next.js 14, React, Tailwind, shadcn/ui | Docker (`web/Dockerfile`), port 3000 | Serves UI + API proxy routes |
| Backend | Flask/Python 3.11, SQLAlchemy | Root `Dockerfile`, port 5000 | Alembic migrations run on boot |
| Database | PostgreSQL 16 | `postgres:16-alpine` container | Data in `pgdata` volume |
| TLS/Proxy | Caddy 2 | Auto-HTTPS on :80/:443 | Single public entrypoint |
| Cache | Redis 7+ | optional | Set `AEON_REDIS_URL` to enable |

The frontend proxies API requests to the backend over the compose network via
`AEON_PYTHON_URL=http://backend:5000`.

---

## Prerequisites

- **Oracle Cloud VM** — Ubuntu 22.04+, shape `VM.Standard.A1.Flex`
  (2–4 OCPU / up to 24 GB RAM on the always-free Ampere tier)
- **Docker + Docker Compose** (installed by `scripts/deploy-oracle.sh`)
- **DNS A record** pointing your domain at the VM's public IP (for HTTPS)
- **Stripe** account (for billing)
- **OpenAI / Anthropic / other LLM** API key (for AI features)

## 1. Environment Variables

All variables live in `/opt/aeon/.env` on the VM and are injected into the
containers by `docker-compose.oci.yml`.

### Backend (Flask kernel)

```bash
# ── Required ────────────────────────────────────────────────────────────────
POSTGRES_PASSWORD=<random>                 # auto-generated by deploy script
AEON_JWT_SECRET=<random-64-char-string>    # openssl rand -base64 48
AEON_ENV=production

# ── Auth / admin seed (first boot only) ─────────────────────────────────────
AEON_ADMIN_EMAIL=admin@yourdomain.com
AEON_ADMIN_PASSWORD=<initial-password>
AEON_ADMIN_NAME=Platform Admin

# ── CORS ────────────────────────────────────────────────────────────────────
AEON_CORS_ALLOWED_ORIGINS=https://app.yourdomain.com

# ── LLM Provider (choose one) ──────────────────────────────────────────────
AEON_LLM_PROVIDER=openai                   # or anthropic, google, stub, …
OPENAI_API_KEY=sk-...                      # required if provider=openai

# ── Encryption ──────────────────────────────────────────────────────────────
AEON_MASTER_KMS_KEY=<random>               # encryption-at-rest master key

# ── Stripe (billing) ────────────────────────────────────────────────────────
STRIPE_API_KEY=sk_live_...                 # or sk_test_... for staging
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_PRICE_TEAM=price_...
STRIPE_PRICE_ENTERPRISE=price_...
```

### Frontend (Next.js)

```bash
# ── Required ────────────────────────────────────────────────────────────────
AUTH_SECRET=<strong random value>          # Auth.js v5 session signing secret
NEXTAUTH_URL=https://app.yourdomain.com
AEON_PYTHON_URL=http://backend:5000        # same-VM kernel over compose net

# ── Optional ────────────────────────────────────────────────────────────────
NEXT_PUBLIC_APP_NAME=AEON OS
NEXT_PUBLIC_APP_URL=https://app.yourdomain.com
```

After editing `.env`, restart with:

```bash
cd /opt/aeon && docker compose -f docker-compose.oci.yml up -d
```

## 2. Stripe Setup

### Required Price IDs

Create these in the Stripe Dashboard:

1. **Team Plan** — Monthly subscription
   - Create a Product → Add a Price (recurring, monthly)
   - Set `STRIPE_PRICE_TEAM` to the price ID

2. **Enterprise Plan** — Monthly subscription
   - Create a Product → Add a Price (recurring, monthly)
   - Set `STRIPE_PRICE_ENTERPRISE` to the price ID

### Webhook Configuration

1. Go to **Stripe Dashboard → Developers → Webhooks**
2. Add endpoint: `https://<your-domain>/api/stripe/webhook` (proxied by
   Caddy → web → backend `/stripe/webhook`)
3. Select events:
   - `checkout.session.completed`
   - `customer.subscription.created`
   - `customer.subscription.updated`
   - `customer.subscription.deleted`
   - `invoice.payment_succeeded`
   - `invoice.payment_failed`
4. Copy the **signing secret** → set as `STRIPE_WEBHOOK_SECRET`

## 3. Security Checklist

### Authentication
- [ ] `AEON_JWT_SECRET` is a strong random string (≥32 chars)
- [ ] `AUTH_SECRET` is stable across restarts/rebuilds
- [ ] `AEON_ENV=production` (disables dev fallbacks)
- [ ] Admin password was rotated after first login (seed password is ignored after first boot)

### Network
- [ ] Only ports 22, 80, 443 are open in the OCI Security List / NSG
- [ ] Postgres and backend are reachable only inside the Docker network
- [ ] HTTPS enforced by Caddy with a valid Let's Encrypt certificate

### Secrets
- [ ] No secrets in git history
- [ ] All API keys set only in `/opt/aeon/.env` on the VM (never committed)
- [ ] `.env` files are gitignored

### Rate Limiting
- [ ] Per-user and per-workspace rate limits are configured
- [ ] Stripe webhook has signature verification enabled

### Data
- [ ] Audit logging is enabled (default)
- [ ] AI execution ledger is recording (default)
- [ ] Backup policies are configured for production data (see below)

### Backups

```bash
# Nightly Postgres dump (add to cron on the VM)
docker compose -f /opt/aeon/docker-compose.oci.yml exec -T postgres \
  pg_dump -U aeon aeon | gzip > /var/backups/aeon-$(date +%F).sql.gz
```

## 4. Monitoring & Observability

### Built-in Endpoints

| Endpoint | Description |
|----------|-------------|
| `GET /health` | Service health with dependency checks |
| `GET /health/detailed` | Full health: DB, governance, Stripe, AI ledger, dead letters |
| `GET /ready` | Readiness: environment, loaded agents, queue status |
| `GET /metrics` | Prometheus metrics |
| `GET /operations/snapshot` | Admin: worker queue, memory, automations |
| `GET /operations/observability` | Admin: AI stats, dependency health, security events |
| `GET /events` | Domain event outbox status |

### Key Metrics to Monitor

- Request rate and latency (from `/metrics`)
- Error rate (5xx responses)
- AI execution cost and token usage (`/ai/ledger/summary`)
- Pending events in outbox (`/events`)
- Dead letter count (`/health/detailed`)
- Automation execution success/failure rate
- Container health: `docker compose ps` and `caddy` access logs on the VM

## 5. Troubleshooting

### Common Issues

| Issue | Solution |
|-------|----------|
| `503 on /health` | Database not reachable — check `POSTGRES_PASSWORD` and `docker compose logs postgres` |
| `401 on all endpoints` | `AEON_JWT_SECRET` not set or mismatched |
| `CORS errors` | `AEON_CORS_ALLOWED_ORIGINS` doesn't include frontend URL |
| `Stripe webhook 400` | `STRIPE_WEBHOOK_SECRET` wrong or missing |
| `Migration errors` | Check `docker compose logs backend`; migrations are fail-closed on boot |
| `Auth.js server configuration error` | Ensure stable `AUTH_SECRET` and correct `NEXTAUTH_URL` in `/opt/aeon/.env`, then recreate containers |
| `Supabase auth/database failure` | Set `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY`; keep `SUPABASE_SERVICE_ROLE_KEY` server-only |
| `Rate limited` | Increase `AEON_RATE_LIMIT_USER` or check for loops |
| Certificate not issued | Verify DNS A record resolves to the VM and ports 80/443 are open |

### Logs

```bash
cd /opt/aeon
docker compose -f docker-compose.oci.yml logs -f backend   # kernel
docker compose -f docker-compose.oci.yml logs -f web       # frontend
docker compose -f docker-compose.oci.yml logs -f caddy     # TLS/proxy

# Local development
python3 aeon_server.py  # Logs to stdout
```

## 6. Rollback Procedure

### Whole stack
```bash
cd /opt/aeon
git -C /opt/aeon/repo checkout <previous-tag-or-sha>   # if repo clone kept
sh scripts/deploy-oracle.sh                            # rebuild + restart
```
Named volumes keep data intact across rollbacks.

### Database
1. Migrations are forward-only; if a migration causes issues, fix forward.
2. For data issues, restore from backup:
   ```bash
   gunzip -c /var/backups/aeon-YYYY-MM-DD.sql.gz | \
     docker compose -f /opt/aeon/docker-compose.oci.yml exec -T postgres \
     psql -U aeon aeon
   ```
